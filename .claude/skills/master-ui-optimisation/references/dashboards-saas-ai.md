# Dashboard, SaaS, and AI Product Reference

## Dashboard
Prioritise:
- scanability
- comparison
- data meaning
- stable navigation
- compact hierarchy

Tables:
- align comparable content
- right-align numeric data when useful
- search/filter/sort when needed
- truncate safely
- de-emphasise inactive rows
- reveal low-frequency actions contextually

Charts:
- answer a question
- choose the simplest appropriate form
- avoid decorative complexity

## SaaS
Avoid:
- arbitrary emoji icons
- random AI-generated colours
- endless cards
- overloaded sidebars
- always-visible advanced settings
- weak billing/usage hierarchy
- meaningless analytics

## AI Products
Consider:
- primary prompt/input
- multimodal attachment affordances
- modes/chips
- integrations
- history
- memory/context
- inline editing
- source/process visibility
- confidence/status
- explicit loading/progress

Latency is a UI problem. Use streaming, skeletons, status, or staged progress where appropriate.
