# Premium Experience Audit

Score each item:

- **2 = Premium**
- **1 = Acceptable / needs polish**
- **0 = Cheap-feeling / broken**

Maximum score: **40**

| Area | Test | Score |
|---|---|---:|
| Core task | Frequent tasks succeed without unnecessary friction. | /2 |
| Correction loops | Users rarely need to correct predictable system mistakes. | /2 |
| Smart defaults | Common choices are inferred or remembered safely. | /2 |
| Context awareness | Relevant context is used intelligently and proportionately. | /2 |
| State preservation | Drafts, filters, position, and workflow context survive appropriately. | /2 |
| Responsiveness | Touch/pointer interactions acknowledge immediately. | /2 |
| Motion continuity | Important transitions explain state changes. | /2 |
| Haptics | Tactile feedback is semantic and restrained where supported. | /2 |
| Keyboard | Mobile keyboard behaviour feels integrated and predictable. | /2 |
| Loading | Waiting states show meaningful progress/structure. | /2 |
| Empty states | Empty screens explain, guide, and fit the product voice. | /2 |
| Error prevention | Predictable mistakes are prevented before submission. | /2 |
| Recovery | Errors preserve work and provide a clear recovery path. | /2 |
| Icons | Iconography is coherent in style and weight. | /2 |
| Illustration | Custom visual character is used deliberately where appropriate. | /2 |
| Performance | Scrolling, navigation, keyboard, and interactions are smooth. | /2 |
| Privacy | Contextual intelligence is permission-aware and data-minimised. | /2 |
| Accessibility | Premium effects respect motion, haptic, text, focus, and contrast needs. | /2 |
| Consistency | Motion, haptics, states, and components follow a system. | /2 |
| Surprise | At least one key flow performs better than the user reasonably expects. | /2 |

## Interpretation

- **37–40** — Exceptional premium craft
- **33–36** — Strong premium experience
- **27–32** — Polished but still ordinary in places
- **20–26** — Functional, visibly under-refined
- **0–19** — Fix friction and product completeness before decoration

## Automatic Failure Flags

Do not approve if:

- core action is unreliable
- user repeatedly re-enters information the app could safely preserve
- a contextual feature is invasive or unexplained
- touch response feels delayed
- animations block task completion
- haptics fire indiscriminately
- keyboard covers essential controls
- loading is unexplained for long-running work
- empty/error states strand the user
- accessibility settings are ignored
- visual polish creates performance jank
- premium effect exists only as decoration while obvious friction remains
