# Visual Foundations Reference

## Hierarchy
Use size, position, weight, contrast, opacity, proximity, and whitespace together.

## Spacing
Use a stable rhythm, commonly multiples of 4. Prefer a small token set over one-off values.

## Proximity
Related items sit closer together than unrelated items.

## Cards
Cards are semantic containers, not decoration. Avoid nested card stacks.

## Typography
Keep product typography compact and systematic; marketing typography can be broader and more expressive.

## Icons
Use one family, consistent visual weight, appropriate size, and tooltips/labels for unfamiliar icons.

## Signifiers
Clickable/selected/disabled/editable states must look different enough to understand.

## States
Interactive components should visibly acknowledge hover, focus, press, disabled, loading, and validation where relevant.

## Grids
Use grids to improve repeated structure and alignment, not as arbitrary constraints.

## Whitespace
Whitespace is active hierarchy. It creates grouping, rhythm, and focus.
