# Motion, Personality, and Mobile Reference

## Motion
Motion should clarify or delight.

Prefer object-specific movement over generic fade-ins.

Good purposes:
- state continuity
- feedback
- hierarchy
- origin/destination
- semantic storytelling

Support reduced motion.

## Micro-interactions
Use for:
- hover
- press
- tooltip
- loading
- toast
- progress
- selection
- focus
- status

## Personality
Define brand flavour in 2–3 words and translate it into:
- radius
- density
- colour
- imagery
- texture
- motion

## Meaningful Richness
Extra visual elements may help if they reinforce product context while preserving focal whitespace.

## Mobile
- 3–4 primary bottom destinations preferred
- 5 practical upper bound
- generous touch targets
- readable scale
- vertical primary flow
- horizontal secondary rails only when useful
- familiar gestures with visible alternatives
- handle safe areas and keyboards
